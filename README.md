Uma página web simples, responsiva e visual para explicar o armazenamento local do navegador e como fazer backup dos dados.

[🌐 Acessar a página Armazenamento-local](https://brunomoraesf.github.io/Armazenamento-local/)

## 💡 Por que este projeto existe?

Criei este arquivo HTML para incluir nos meus próprios projetos. Quero que as pessoas saibam como suas informações são armazenadas e tenham a tranquilidade de entender que, ao utilizar o armazenamento local do navegador, seus dados não são enviados para a internet. Eles ficam salvos apenas no próprio dispositivo, dentro do navegador utilizado.

Esta página explica de forma simples como funciona esse armazenamento e como fazer backups para guardar ou transferir as informações.
