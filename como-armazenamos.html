Armazenamento Local

Seus dados ficam armazenados diretamente no seu navegador.

Nada é enviado para servidores externos.

Este aplicativo foi feito para funcionar inteiramente no seu navegador.

Atenção especial

Nenhuma informação sua é enviada para a internet. Seus registros, checklists, tipos de documento e anotações existem apenas dentro do seu navegador, no seu computador ou celular.

Você pode inclusive desconectar o Wi-Fi ou desligar os dados móveis e continuar usando o aplicativo normalmente, porque ele não precisa de conexão para funcionar.

✓ O que fica salvo

  • Tudo o que você digita ou cadastra
  • Todas as configurações que você faz
  • Todos os textos que você escreve

! Onde fica salvo

  • No localStorage do seu navegador — uma área reservada a cada site.
  • Vinculado ao endereço do app (domínio) e ao dispositivo onde foi aberto.
  • Se abrir em outro navegador (Chrome → Firefox), os dados não aparecem automaticamente.
  • Para transferir entre dispositivos, use o backup em arquivo .json.

✕ O que nunca acontece

  • Não enviamos nada para servidores nossos ou de terceiros.
  • Não existe conta, login, e-mail ou senha.
  • Não há cookies de rastreamento, analytics ou anúncios.
  • Ninguém além de você consegue acessar o conteúdo salvo.

Um simples Ctrl+S mental: cada letra que você digita vira um arquivo no seu próprio computador.

E se eu quiser guardar uma cópia?

Como os dados ficam só no navegador, um dia você pode querer levá-los para outro computador, formatar a máquina ou simplesmente ter uma cópia de segurança. Para isso, o app oferece backup em arquivo .json.

📤
Exportar
Baixa um arquivo .json com todos os seus dados. Guarde onde quiser — pen drive, nuvem pessoal, e-mail para você mesmo.
📥
Importar
Lê um arquivo .json e restaura tudo no navegador atual. Útil ao trocar de computador ou recuperar um backup antigo.

O arquivo .json é um formato aberto — você pode abri-lo em qualquer editor de texto para conferir o conteúdo, e nada dentro dele sai do seu controle.

Sobre o Clippy: o personagem da barra inferior busca frases motivacionais em uma API pública de conselhos (adviceslip.com) e as traduz. Nenhum dado pessoal seu é enviado — apenas uma requisição anônima para buscar o texto do dia. Se você ficar sem internet, o Clippy simplesmente mostra uma frase padrão, e todo o resto do app continua funcionando.
